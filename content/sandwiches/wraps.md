# Wraps

Baseline amounts per wrap — adjust to taste.

## Kipfilet variant

```ingredients
servings: 1
| | kipfilet (of gerookte kipfilet)
| | paar plakjes komkommer
1/2 | bosui |
| | snufje peper
```

## Groenten wrap

```ingredients
servings: 1
1/4 | rode paprika |
| | handje rucola
1/2 | bosui |
| | snufje peper
| | snufje chilipoeder
```

## Wrap met kip, sla en komkommer

```ingredients
servings: 1
1 | tl | roomkaas met kruiden
| | handje ijsbergsla/eikenblad melange
| | plakje kipfilet (of gerookte kip)
| | paar plakjes komkommer
| | snufje peper
```
